# ورود کاتالوگ داواخانا و بگوسیب

این فرایند کاتالوگ عمومی دو منبع را جمع‌آوری و با مدل‌های فعلی Laravel وارد می‌کند. متن تجاری فروشگاه‌ها بازنشر نمی‌شود؛ توضیح مستقل از مشخصات ساختاری محصول ساخته می‌شود. تصویر اصلی به‌صورت فایل محلی ذخیره می‌شود.

## اجرای استخراج و مقایسه

```powershell
node tools/catalog-extract.mjs --bego-only
node tools/catalog-davaxana-api.mjs
node tools/catalog-recover.mjs
node tools/catalog-prepare.mjs
node tools/catalog-prepare.mjs --images
```

- برای ادامهٔ داواخانا بدون دریافت دوبارهٔ بگوسیب: `node tools/catalog-extract.mjs --dava-only`.
- خروجی‌ها در `storage/app/catalog-import` ذخیره می‌شوند و داخل Git نیستند.
- `records` فقط نام، مشخصات، مسیر دسته، نشانی تصویر و امتیاز کامل‌بودن منبع را نگه می‌دارد. قیمت و موجودی و انقضا از مبدأ نگهداری نمی‌شوند.
- `catalog-ready.json` فایل آمادهٔ ورود است. `comparison.json` گزارش تکراری‌ها، منبع انتخاب‌شده و تطبیق‌های نیازمند بررسی است.
- نام‌ها با یکسان‌سازی ی/ک، ارقام، ترتیب واژه‌ها و واحدها مقایسه می‌شوند. تفاوت تعداد بسته، دوز، رنگ و طعم مانع ادغام خودکار است. موارد نامطمئن جدا می‌مانند.
- رابط عمومی بگوسیب با کل فهرست نقشهٔ محصولات تطبیق داده می‌شود. فهرست عمومی داواخانا نیز با نقشهٔ قدیمی ترکیب می‌شود؛ تنها از مسیرهای خواندن محصولات که خود فروشگاه استفاده می‌کند داده گرفته می‌شود و حساب کاربری لازم نیست. نقشهٔ داواخانا دامنهٔ قدیمی دارد؛ مسیر شناسهٔ همان محصول روی davaxana.com خوانده می‌شود.
- دریافت‌های ناموفق در گزارش خطا باقی می‌مانند و نباید از گزارش نهایی حذف شوند.

## ورود

```powershell
$env:PHP_INI_SCAN_DIR = "$PWD\tools\php\ini"
php artisan migrate
php -d memory_limit=512M artisan catalog:import storage/app/catalog-import/catalog-ready.json --dry-run
php -d memory_limit=512M artisan catalog:import storage/app/catalog-import/catalog-ready.json
php artisan storage:link
```

قبل از اجرای واقعی، برای پایگاه دادهٔ محلی SQLite دستور `php tools/catalog-backup.php` را اجرا کنید. پس از ورود با `php -d memory_limit=512M tools/catalog-verify.php` شمارش، تصاویر، موجودی و خالی‌بودن فیلدهای مبدأ را بررسی کنید. فرمان با تراکنش اجرا می‌شود و در خطای ورود، داده‌های همان اجرا بازمی‌گردند.

محصولات جدید شناسهٔ محلی `DKH-000001` و بعدی می‌گیرند؛ پیشوند با `--sku-prefix` قابل تنظیم است. بارکد، قیمت، برند، canonical مبدأ و سایر فیلدهای تجاری منتقل نمی‌شوند. انقضای محصول و موجودی خالی است و برای هر محصول فقط ۱۰ عدد موجودی اولیه ثبت می‌شود. محصول بدون قیمت قابل خرید نیست و پس از ورود از پنل موجود قابل ویرایش است.

جدول `catalog_import_sources` ارتباط محصول با منبع و امتیاز مقایسه را حفظ می‌کند. اجرای دوباره محصولات را تکثیر نمی‌کند و نام، متن، قیمت، انقضا یا موجودی ویرایش‌شدهٔ محصول قبلی را تغییر نمی‌دهد. محصولات موجود پیش از این ورود حذف یا بازنویسی نمی‌شوند.

دسته‌های مادر محصولات تمام زیرشاخه‌ها را نمایش می‌دهند؛ شمارش محصولات صفحهٔ اصلی و فهرست دسته‌ها هم زیرشاخه‌ها را شامل می‌شود.

## بررسی

```powershell
node --test tools/catalog-prepare.test.mjs
php artisan test --filter='CatalogImportTest|CatalogCategoryTreeTest'
```

این بررسی‌ها تفاوت بسته و طعم، پیش‌فرض‌های ورود، حفظ محصولات قبلی، ورود دوباره بدون افزایش موجودی و نمایش سلسله‌مراتب دسته‌ها را پوشش می‌دهند.

پس از dry-run موفق و در صورت تغییرنکردن فایل‌های تصویر، گزینهٔ `--skip-image-inspection` از خواندن دوبارهٔ همان تصاویر جلوگیری می‌کند؛ اعتبارسنجی نام، متن، دسته، شناسهٔ منبع و مسیر تصویر همچنان انجام می‌شود. محصول فاقد دسته در «سایر محصولات» قرار می‌گیرد.
