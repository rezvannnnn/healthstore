# نسخهٔ کامل کاتالوگ — ۲۰۲۶/۱۰/۲۲

این پوشه کد نسخهٔ واردسازی‌شده و یک دیتابیس کاتالوگ مستقل دارد. اطلاعات کاربران، رمزها، نشست‌ها، سفارش‌ها، پرداخت‌ها و تنظیمات خصوصی در این نسخه نیستند. فایل `.env` باید در مقصد ساخته شود.

۱. در این پوشه `composer install` و سپس `npm ci` اجرا کنید.
۲. `.env.example` را به `.env` کپی کنید و `php artisan key:generate` را اجرا کنید.
۳. فایل `catalog-snapshot.sqlite` را به `database/database.sqlite` کپی کنید. این کار را فقط روی نصب تازه انجام دهید تا دیتابیس موجود بازنویسی نشود.
۴. اتصال SQLite و آدرس سایت را در `.env` تنظیم کنید.
۵. پوشه‌های runtime زیر `storage/framework` را در صورت نیاز بسازید و `php artisan storage:link` را اجرا کنید.
۶. `npm run build` و سپس `php artisan serve --host=127.0.0.1 --port=8001` را اجرا کنید.

در Windows پیش از اجرای PHP متغیر زیر را تنظیم کنید:

```powershell
$env:PHP_INI_SCAN_DIR = "$PWD\tools\php\ini"
```

فایل `CATALOG-SNAPSHOT.json` شمارش و SHA-256 دیتابیس را دارد. تصاویر در `storage/app/public/products` قرار دارند. کاتالوگ شامل ۱۲٬۸۹۴ محصول (۱۲٬۷۸۵ محصول جدید)، ۲۹۹ دسته و موجودی ۱۰ عدد برای محصولات جدید است. برای ساخت حساب مدیریت، تنظیمات مدیر را در `.env` محلی خود وارد کنید و راهنمای README را دنبال کنید؛ هیچ حساب کاربری از سیستم مبدأ منتشر نشده است.
